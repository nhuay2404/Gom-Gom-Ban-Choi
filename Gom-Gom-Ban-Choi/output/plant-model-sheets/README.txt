SPRITE SHEETS - ORIGINAL GAME PLANT MODELS

8 models, 64 rendered views in total.
Each PNG has a transparent background and measures 1536 x 768 pixels.
Layout: 4 columns x 2 rows; each frame is 384 x 384 pixels.
Read frames from left to right, then top to bottom.
View angles: 0, 45, 90, 135, 180, 225, 270, 315 degrees.
Camera elevation: 30 degrees. Angle 0 looks from +Z; angle 90 from +X.
Framing and scale remain fixed across the eight views of each model.

Models:
- corner-bush-1 through corner-bush-4: four original garden corner bushes
- vegbed: tomato bed
- sunflowers: sunflower bed
- sunflowers-lavender: lavender bed
- catnip: catnip bed

Original model geometry, planters/ground patches, materials and toon lighting
are retained. Outside each rendered model is transparent.
