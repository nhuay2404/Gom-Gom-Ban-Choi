# The Pocket Mentor for Video Game UX/UI (Simon Brewer, 2025)

Routledge/CRC Press, "Pocket Mentors for Games Careers" series, ~177 pp. Author: Principal UI/UX Designer at Supermassive Games (previously Rebellion, Rocksteady, Sony, Gree; started in QA in 2008). Half craft handbook, half career guide. Practitioner voice, opinionated, light on data, examples are almost all AAA console/PC games (Bioshock, Dead Space, Rocket League, Helldivers 2, Last of Us II, GTA V). Mobile appears only as screen size, touch input and "live service and mobile games frequently trigger free rewards" (p. 39). Free-to-play monetisation is never discussed as a topic; popups/offers/shops appear only in passing (store price + checkout button must be discoverable, p. 29-30; modals sparingly, p. 106).

## Distinctive claims (digest)
- Games UX is "the careful balance of friction", the opposite of app UX; a frictionless game is "a screensaver" (pp. 4, 76, 167).
- Never use full-screen colour-blind filters; design so colour is never the only carrier (p. 111).
- Designers who see players miss a mechanic often "fix it in UI" by adding more UI; the real problem is competing attention (p. 85).
- Accessibility is not "making it easier"; difficulty is relative, barriers are the issue; three approaches: tools through, path around, skip (pp. 61-62).
- Aesthetic-usability effect licenses real visual craft; "UI Art is dying" complaint, the Rule of Cool (pp. 39, 78, 95).
- Four-way UI representation (diegetic, non-diegetic, spatial, meta) with explicit cost/schedule warning (pp. 80-83).
- Modals are interruptions to be used infrequently (p. 106); 40% localisation buffer; 18 pt minimum text claim (pp. 115-116).
- Seniority is best read from how someone handles feedback, not the title (p. 15).
